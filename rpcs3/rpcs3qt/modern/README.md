# RPCS3 Modern Frontend

This directory contains the experimental modern desktop frontend for the fork.

The initial implementation is intentionally isolated from the emulator core. During early development the legacy RPCS3 interface remains available and exposes a **View → Modern UI Preview** entry that opens the new shell.

The preview shell is expected to evolve into the primary UI only after real game-library data, boot actions, settings, controllers and RPCN frontend integration are proven stable.
